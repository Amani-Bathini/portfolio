## 💻 How to Run the Website

### Option 1: Direct File Launch (No Setup Required)
Simply double-click `index.html` or right-click and choose **Open with > Chrome / Edge / Firefox / Safari**.

### Option 2: Local HTTP Server (Recommended)
You can serve the portfolio locally using any standard command-line utility:

**Using Python:**
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

**Using Node / npx:**
```bash
npx serve .
```
